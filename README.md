# javascript-racingcar-precourse

## 🧩 자동차 경주 게임 — 기능 목록 정리 (보완 버전)

### 1️⃣ **자동차 이름 입력 및 검증**

- [ ] 사용자로부터 자동차 이름 문자열 입력 (`readLineAsync`)
- [ ] **입력 포맷 검증**
  - 쉼표(`,`) 기준으로 분리 (이름 사이 공백 제거)
  - 빈 이름(`",,"`, `","` 등) 입력 시 `[ERROR]` 출력 후 종료
  - 각 이름은 **1~5자** 사이여야 함
    → 초과 시 `[ERROR]` 출력 후 종료
  - **공백, 쉼표, 빈 문자열만 금지**
  - **기타 특수문자는 허용**
- [ ] 유효한 이름 리스트 저장 (`cars` 배열)
- [ ] 배열 길이로 자동차 개수 파악

---

### 2️⃣ **시도할 횟수 입력 및 검증**

- [ ] 사용자에게 시도 횟수 입력받기 (`readLineAsync`)
- [ ] 입력값이 **정수인지 확인**
  - 음수, 0, 소수, 문자 입력 시 `[ERROR]` 출력 후 종료
- [ ] 정수형으로 변환하여 변수 `rounds`에 저장

---

### 3️⃣ **경주 초기화**

- [ ] 모든 자동차 객체 생성
      예시: `{ name: "pobi", distance: 0 }`
- [ ] 초기 상태 출력 준비 (0회차 전진 결과는 표시 안 함)

---

### 4️⃣ **랜덤 전진 로직**

- [ ] **각 회차별 반복 (1 ~ rounds)**
  - 각 자동차별로 `Random.pickNumberInRange(0, 9)` 호출
  - 랜덤값 ≥ 4 → `distance++`
  - 랜덤값 < 4 → 정지
- [ ] 각 회차 종료 후 현재 상태 출력
  - `"자동차명 : -"` 형식으로 거리만큼 출력
- [ ] 모든 회차 종료 시까지 반복

---

### 5️⃣ **우승자 판정**

- [ ] 모든 자동차의 `distance` 중 최댓값 계산
- [ ] 최댓값을 가진 자동차(복수 가능) 이름 배열 추출
- [ ] 쉼표(`,` )로 구분하여 출력

  ```
  최종 우승자 : pobi, jun

  ```

---

### 6️⃣ **입출력 포맷**

- [ ] 입력 전 안내 메시지 출력
  - “경주할 자동차 이름을 입력하세요. (이름은 쉼표(,) 기준으로 구분)”
  - “시도할 횟수는 몇 회인가요?”
- [ ] 출력 형식은 요구사항 예시와 동일해야 함
      (공백, 개행, 콜론 위치까지 동일하게 유지)
- [ ] `Console.print()` 사용 (console.log 사용 금지)
